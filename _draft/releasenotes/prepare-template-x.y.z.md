```
About flavor-specific notes
- These notes mention only changes for that expansion
- Changes must *not* be stated explicitly as specific to that flavor
  - For example, never write "New Spell Alert: Focus Fire (Mists of Pandaria)"
  - Prefer flavorless text "New Spell Alert: Focus Fire"
- Special case of the above rule: Season of Discovery
  - Season of Discovery should be stated explicitly
  - This is because there is a single build for SoD and non-SoD Vanilla
- If 2 flavors share the exact same notes, copy-paste is not needed
  - There will still be 2 different packages that will be uploaded
```


# GitHub
```
About GitHub notes
- These notes aggregate changes for all flavors (i.e. all expansions)
- Flavor-specific changes, such as MoP-only changes, should be stated explicitly
  - For example, please write "New Spell Alert: Focus Fire (Mists of Pandaria)"
- Changes that apply to all flavors must *not* list each and every flavor
```

```
Specific things about Discord notes
```
