# SpellActivationOverlay 2.7.10
@here I am pleased to announce the newest release of SpellActivationOverlay, version 2.7.10
## Bug Fixes
### Addon Interaction
Macro-based glowing buttons should glow as intended (for real this time).

_Developer's Note: After careful investigation, this issue is caused by both Bartender and the game client. If either fixes their side (not necessarily both), it would work. However, without knowing when one or the other fixes their stuff, SpellActivationOverlay implements a(nother) temporary fix. This shall be reverted once Bartender developers or Blizzard (or both) update their code._
### :mage~1:  Mage
Pyroblast should always glows as intended during Hot Streak (Mists of Pandaria). This only affected players who use macros with the game client's native action buttons.

_Developer's Note: Although the fix is completely different, this issue is related to Bartender's issue. Incidentally, all _temporary_ buttons added in version 2.7.4 and 2.7.5 were broken since Bartender last update when put in macros. And these macros should now work in Bartender since version 2.7.10._
