# SpellActivationOverlay 3.0
@here I am HYPED to announce the newest release of SpellActivationOverlay, version 3.0!  :tada:
## General
### Spell Alerts
Spell Alerts now have a countdown number, similar to the shrinking effect but as numeric value.
- This effect is disabled by default; enter /sao to enable or disable it
- _Visual Countdown_ rules the shrinking, formerly known _Spell Alert Progressive Timer_
- _Text Size_ rules the new number functionality; it starts at Off (disabled) and can be increased to select the font size
Please note, some countdown numbers are not displayed on purpose to avoid confusion.

Spell Alerts can now have a shifted position
- Alerts can share the same location (Top/Left/Right) without overlapping
- Previously, sharing used other techniques such as scaling
- This new technique should provide richer spell alerts with less confusion
### User Interface
The options panel (`/sao`) has been slightly redesigned to make room for the new countdown number functionality.
