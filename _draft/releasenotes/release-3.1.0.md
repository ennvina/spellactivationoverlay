# SpellActivationOverlay 3.1.0
@here I am pleased to announce the newest release of SpellActivationOverlay, version 3.1.0
## Classes
### :mage~1:  Mage
New Spell Alert
- Arcane Tunneling (Season of Discovery)
### :rogue:  Rogue
New Glowing Button
- Shank (Forever)
### :warrior:  Warrior
Updated Spell Alert
- Overpower is displayed in all stances (Forever)
Updated Glowing Button
- Overpower glows in all stances (Forever)
## Bug Fixes
### Sounds
Sounds should no longer cause issues during combat (Forever)
### :druid:  Druid
The Omen of Clarity spell alert should now display correctly in Cat Form (Forever)
### :mage~1:  Mage
Clearcasting option now longer appears twice (Era, TBC, Wrath, Cata, MoP)
### :warrior:  Warrior
Execute should no longer glow without a target (Forever)
## Miscellaneous
Spell alerts fade out more smoothly after leaving combat
- It was fading out from 100% to 50% in 0.2 second
- It now fades out from 100% to 60% in 3 seconds
The result is still dimming spell alerts out of combat, but with a much less brutal transition.
